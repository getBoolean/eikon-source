Eikon

A prototype toward an iPhone and iPad app that would run Windows and Linux games. It is not a working emulator, and it is not a jailbreak tool.

Nothing here runs a game on a device. This page is not a live Sileo source.

The intended stack, not yet integrated, is FEX-Emu for Linux x86-64 and Wine under FEX for Windows. The bundled demos, Signal Drift and Brickline, are original sketches.
