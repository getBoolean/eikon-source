# eikon-source

The Sileo source for Eikon, served by GitHub Pages from `main` `/docs`.

Add it in Sileo: https://getboolean.github.io/eikon-source/

This repository holds **package index files only**. The debs are GitHub Release
assets on the app repository. Everything under `docs/` is generated by
`scripts/repo/build_index.py` in https://github.com/getBoolean/eikon and is overwritten on each publish;
don't edit it by hand.
