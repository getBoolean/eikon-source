# Eikon source

Sileo source for Eikon. Apt files only. The app is developed at https://github.com/getBoolean/eikon

This is an unfinished prototype. It is not a working emulator, and it is not a live Sileo source. Nothing here runs a game. GitHub Pages is not serving this yet.

Intended URL, once Pages is turned on:

https://getboolean.github.io/eikon-source

Package id: `com.getboolean.eikon`
Architecture: `iphoneos-arm64`
Install root: `/var/jb` (Dopamine 2 rootless)

There is no JIT bypass, no exploit, and no commercial games.
